# Seahorse v1 — legacy

Frozen source from the original `v1.1.0` release, commit
`e953e2302b30b04ecb7fde623354948a98350217`. There are no active v1 users;
this profile preserves the firmware for recovery or a future standalone build.
The original README is retained as [HISTORICAL_README.md](HISTORICAL_README.md).

This directory is a standalone ZMK project and is excluded from the default
v2 workflow. Export it using the [version guide](https://github.com/nathansbradshaw/zmk-the-seahorse/blob/main/docs/firmware-versions.md),
or export the exact `v1.1.0` tag if original file-for-file source is needed.

The original manifest and workflow are retained. They have not been upgraded
or rebuilt during this consolidation; historical dependencies may need a
separate compatibility update. V2's TrackPoint/Studio configuration and its
Bluetooth changes have not been applied to this legacy profile.

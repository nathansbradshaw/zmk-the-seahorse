# Seahorse nice!view screen

This shield ships inside the v2 firmware profile and is selected by its right
build. It preserves the deployed nice!view gem status widgets and adds a
USB-only, once-per-connection Bad Apple video to the middle panel.

See [BAD_APPLE.md](BAD_APPLE.md) for behavior, asset credits, source provenance,
Rust build requirements, regeneration, and tests. The original upstream
documentation is preserved in [UPSTREAM_README.md](UPSTREAM_README.md).
